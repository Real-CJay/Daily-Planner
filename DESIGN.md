# Running Rebuild — Adapted Dual-Theme Design System

- **Light Mode Inspiration:** Flomo (`flomoapp.com`) — calm whitespace, `#FFFFFF` surfaces, `#176D3E` / `#2CCC74` green accents, `#747C84` cool muted text, `#F4DCA4` subtle sand callouts, Barlow + Inter typography.
- **Dark Mode Inspiration:** Morgen (`morgen.so`) — `#191A23` canvas, `#21222D` elevated surfaces, `#313444` hairline borders, `#FFFFFF` / `#CBCCCC` text, `#FF8295` / `#C84A59` coral-rose and `#F3C26A` warm gold accents, `#76879D` / `#3A4554` slate controls.
- **Numeric Precision:** `JetBrains Mono` with `tabular-nums` for all distances, paces, durations, splits, and dates.
